# Inline complete predecessor guard r421–r426

CONTRACT-001–003, proposed ADR-001 and the r394 ingest design govern this authorized synthetic native experiment. The previous r418–r420 turn was progress: a bounded physical overlay intervention and exact preservation/read results changed the next action and were committed/pushed. This continuation tests a material ingest alternative rather than another lookup-only benchmark.

## Intervention

`inline_guard_sql_r421.py` generates an update/delete-only MERGE over the existing normalized mutation-source shape. It matches hash AND complete source/relationship/id, compares all20before fields (null-safe, STRING content as UTF-8 bytes), checks version progression and unchanged after identity for live replacements, and raises an error on a bad predecessor. Its matched deletion predicate performs that guard for updates as well; a false guard does not silently skip a write. The missing-match INSERT arm raises an error rather than inserting an absent expected predecessor. Normalized source uniqueness, exact original/current/tombstone partition and origin validation remain prerequisites. This helper is not a general inserts/replay/resurrection publisher or a production worker fence.

On existing warehouse2439e1f2e37ac563, native controls use six complete deterministic Truss-shaped carriers, five updates and one deletion, in an isolated LC/CDF table. No canonical role table is mutated. The source includes lexical exact-number/null properties, retained content, typed endpoints and source origins; those fields are checked as complete carrier digests.
