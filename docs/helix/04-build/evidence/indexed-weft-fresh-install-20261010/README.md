The documented virtual-environment setup, sparse public distribution checkout,
installation and original-request compilation passed using committed Ashlar
2783aef and the independently admitted Weft index at41a42ed. The original
3,203-byte `columns-native:64-empty-column-column` request produced exactly the
16,292-byte original compiler stdout. No SQL/model/binding rewrite was used.
A separate fresh CLI process passed again with the original package directory
renamed and unavailable; the directory was restored afterwards.

All installed Ashlar Python source bytes match their selected committed inputs.
The57-file source export is the package/documentation slice, not the complete
repository or external build/runtime closure. The original setup wheel size/hash
was observed, but the wheel and full build log were not retained; this is an
installed-source and protocol proof, not a reproducible-wheel claim.

The host was observed as macOS27.0.1/arm64/Python3.9.6. Both Ashlar CI gates and
the Weft portability repair CI were terminal-success before installation.
The original public fixture publication is not a live Ashlar publication or
authorization grant. This proof starts no database/graph engine and establishes
no native query, latest LEFT compiler, Truss, Fabric, OTel receiver or production
qualification. Actual compiler stdout and safe provenance are retained separately
from diagnostics. Ordinary file writes do not promise crash durability.
