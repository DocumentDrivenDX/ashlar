# Paired edge expression experiment (2026-10-23)

This bounded local pair changes only the arithmetic for `floor(pmod(id,5)/2)` in the synthetic edge fixture. The replacement uses `pmod(id,5) DIV 2`. The remainder is always 0 through 4, so the expressions agree; a 100,001-id exhaustive Spark comparison and explicit values around 2^53 and signed BIGINT maximum found no mismatch. For an isolated Spark projection over `range(225000000)`, optimized and physical plans differ in the target remainder expression: baseline `FLOOR(cast(pmod(id, 5) as double) / 2.0)`, candidate `(pmod(id, 5) div 2)`.

A broader attempted substitution of `id DIV 5` for `floor(id/5)` was rejected: the baseline converts BIGINT to double, so the two expressions diverge near BIGINT maximum. It was not used in this pair.

Both complete harness runs passed sequentially under an enforced 300-second supervisor deadline (the source harness itself allows 570 seconds), with 18 partitions, ZSTD, exact same source commit/wheel/runtime, and the same 45M node / 225M edge fixture. Each wrote 225M edge rows across 18 files; edge active bytes were identical. Baseline edge-write time was 25.254s; candidate was 26.042s (3.12% slower). The full sample harness did not capture the INSERT physical plan. The isolated projection plan proves the expression changes the generated plan, but does not establish that the INSERT write plan retained a separate operator or that the optimizer cost changed. This result does not support the candidate as a performance optimization.

The two measured output trees totaled 6,172,519,047 bytes, below the requested 10,000,000,000-byte ceiling. That output ceiling was not programmatically enforced during the run; the retained supervisor enforces the time deadline only. The output directories were removed after copying full JSON results and logs here. The outer supervisor body (the stdin source passed to the recorded Python `-B -` invocation), both reproduction harnesses, tiny-probe script and observed summary, plus their hashes, are included. The supervisor enforced the combined wall-clock deadline by terminating its child process group; output bytes were measured after the runs, not guarded during execution. The tiny-probe output is summarized from the completed tool result; no new Spark session was started for this amendment. No Ashlar source changed; no publication, ACK, graph engine or 1B/5B run occurred.
