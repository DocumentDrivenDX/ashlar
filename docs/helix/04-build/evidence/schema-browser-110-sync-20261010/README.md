# Ashlar schema-browser 1.1.0 sync

Ashlar serves the complete unmodified public UMF browser package, including lazy
chunks, license notices and its versioned host contract. The separate Ashlar host
uses public mount, select and destroy APIs with nine unchanged original schemas.

The named latest UMF commit has identical runtime-producing tracked source to the
released package; its example host changed. Exact commits, package and closure
pins are retained here. The package itself lives in the website asset tree and
is not duplicated in this evidence folder.

Cached Chromium checked desktop/mobile source and download bytes, all eight
logical record member layouts, retained unknown Delta extension content, hash
navigation and mount cleanup. These are browser interpretation checks; they do
not establish native Delta validation/enforcement or broader browser support.
