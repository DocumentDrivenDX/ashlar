# Shared native SDK read conformance

The optional `--conformance-root` hook in `tools/check_typed_sdk_native.py` runs
UMF's repository-only shared suite against actual local AshlarTarget instances
and original compiled catalogs. Missing requested tooling refuses before owned
service setup. The actual native oracle independently reads retained Delta
versions through Spark, not through the SDK under test.

The final `native-r2` campaign passes the original 17 named native checks plus a
summary asserting all eight shared cases. `shared-conformance.json` enumerates
every exercised case and native-query observations. Empty completeness comes
from the native manifest; failure/alias cases use real retained-file removal,
rename and replacement UUIDs. The replacement has the requested Delta version
available, so original held native policy refuses its different UUID. After-fetch
alias mutation observes actual closing identity queries and releases no rows.
The shared continuation case changes actual owner-policy context and proves old
token refusal plus a fresh read. Separate unchanged harness witnesses retain
P1/P2 and missing-retained-file continuation coverage. No substituted fake page
or authority is used for native acceptance.

The first attempt is preserved in `native-r1`: its replacement table lacked the
original pinned version and failed with AnalysisException before the intended
identity gate. Correcting that fixture and exact native exception expectation
did not change production runtime, SDK assertions or operation budgets. Both
attempts stopped owned PostgreSQL and Spark; the final attempt exits zero.

installed-payload hashes. These receipts qualify this scalar local
