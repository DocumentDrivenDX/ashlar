public-main-derived UMF 0.5.6 candidate at commit
`9a11ae5c04c23f0cc0ae1d61a27c4d7a64819b08` (based on public UMF 0.5.5 commit
`009c042545a17b49ea857eff22d0fcf3fd71ef44`). This is an unreleased upstream
candidate, not a new Ashlar dependency release. The managed Delta generator and
native behavior are outside this local bridge receipt.

```sh
PYTHONPATH=src:tests /private/tmp/ashlar-release-20261021-m3rde5p2/venv/bin/python -m unittest -v \
  tests.test_local_current_delta4_umf \
  tests.test_local_current_xxhash64_profile
```

This includes all six original role sources, closed proposal/disposition checks,
the local Delta DDL loop with inert Spark, and selected `.4` profile controls.
No Spark or Delta process was started. The result does not qualify table creation,
writer settings in a real runtime, Delta protocol/footers, resume behavior,
publication, ACK, managed Unity Catalog or Truss source/feed behavior.
