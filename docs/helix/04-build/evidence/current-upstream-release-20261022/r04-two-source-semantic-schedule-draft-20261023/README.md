# R04 current-core two-source semantic schedule draft

This is a reviewable semantic draft only. It is deliberately not frozen: the canonical schedule digest, accepted A/B source IDs, request bytes, provider-assigned IDs, feed pages, cursors, writer positions, event inventories and publication vectors are null. The file checksums for this draft are archival checksums, not a schedule identity.

The draft preserves the required global order `A1, B1, A2, B2, A3, B3, A4, B4`, with each source's R1-created Person symbolically targeted by its own R2 update and R3 delete. It separates A/B authority and requires source-qualified object, edge and endpoint identity. The current UMF 0.10 example provides a type/property vocabulary witness only; it is not accepted R04 source evidence. A4/B4 remain additive-candidate placeholders pending the exact independently accepted model/extension.

The independent prefix oracle now starts from independently pinned complete A/B baseline bags and progress; prefix zero does not assert an empty graph. Later prefixes are the baseline plus only completed R04 deltas. It separates publication-manifest progress from protected source ACK checkpoints and leaves R3 incident-edge closure unresolved until one policy is fixed before schedule freeze. It requires full vectors, exact presence/value bags, edge identity/endpoints, history, tombstones, schema revisions and source-specific ACK only after independent durable verification. It does not derive expectations from SQL or native output. The closing-evidence register separately requires exact replay/no-extra-commit, fresh-process journal restart, uncertain/missing-journal refusal, breaking-evolution refusal, a positive retained read within the retention interval, and a separate expired-version negative refusal.

The exact missing inputs are listed in `missing-authoritative-pins.json` and `closing-evidence-register-draft.json`. In particular R03 A migration/resume, genesis publication/ACK and seed readback are not complete, and independent B acceptance/installation/feed/consumer/ACK custody is absent. Authoritative IDs and proof of intended local-ID overlap are also required before a schedule can be frozen. No source mutation, feed read, native publication, ACK, or commit was performed for this draft.

Governing references are in the schedule JSON and the 2026-10-23 offline preparation status. The 2026-10-21 owner decision approves staged feed-page binding; the 2026-10-23 owner decision approves per-slot request-freeze timing. Neither authorizes execution.
