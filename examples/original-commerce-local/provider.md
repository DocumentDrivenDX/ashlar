# Explicit original-commerce query provider

Copy [query-provider.template.py](query-provider.template.py) to an absolute operator-owned path. Replace `CONFIGURATION`, `CONFIGURATION_SHA256`, and `CONTAINER` with the canonical absolute retained publication configuration, its independently selected SHA256, and the explicit private fixture container name. Unfilled placeholders refuse. Hash the completed provider and pass its absolute path and digest to `query-commerce-implicit-arithmetic` using `--session-provider` and `--session-provider-sha256`, with `--postgres-profile explicit-loopback` and the matching explicit endpoint. Select the installed Ashlar, Weft 0.4.2 index/installation, declared original pack and runtime resources separately through the query command.

The example uses public `parse_original_commerce_local` and `original_commerce_local_source_ports` owners. A bounded, nonsymlink regular configuration snapshot must match the selected digest and is renewed before the factories return. The endpoint must match its explicit container/host/port/database selection. Only the registered reader and protected ACK roles can open sessions: the reader uses `registration.source.connection_factory`; ACK uses `registration.metadata_factory`. Writer and foreign roles refuse. The existing local adapter rejects ambient PostgreSQL credential/connection discovery; this example provisions nothing and supplies no grants or legacy fallback.

Provider code and its imports are trusted operator code, not a sandbox. Configuration hashes prove byte correspondence, not source authority. The construction-time configuration renewal does not establish uninterrupted configuration custody through later query execution. The query command owns captured provider/pack renewal; the current public reader and source/ACK owners must independently admit ordinary identity, role, signature, source checkpoint, journal/reservations and the complete native publication vector, and complete their closing checks before report release. Factory construction alone proves none of those facts.

This reusable composition is verified with inert public typed registrations and callbacks. It does not independently qualify a native query, a PostgreSQL installation, production security or real Truss integration. See [CONTRACT-001](../../docs/helix/02-design/contracts/CONTRACT-001-publication-boundary.md) and [CONTRACT-004](../../docs/helix/02-design/contracts/CONTRACT-004-publication-resolver.md) for the governing authority and custody boundaries.
