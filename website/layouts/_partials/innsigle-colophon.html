An edited-but-not-resealed page renders no seal and emits a build warning, rather than a seal that would fail verification. The signature covers the markdown source, never these HTML bytes. The page quotes the source attestation verbatim as application/innsigle+json so a reader can verify it against the source file themselves. Required mounts (see integrations/hugo/README.md, or run `innsigle init --hugo` to write them): .innsigle/public → assets/innsigle (claims + keys, build-time) .innsigle/public → static/.well-known/innsigle (claims + keys, published) → assets/content-src (source bytes, to re-hash) Call it from wherever your theme ends a page.
