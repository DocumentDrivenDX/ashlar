# Ashlar microsite

A Hugo extended 0.167.0 site. `content/` holds seven authored pages; shared layouts render
the design system. `pages.yml` builds it on every change to `website/` and deploys on `main`.

The schema browser is not committed. The build fetches the published
`@documentdrivendx/umf-schema-browser` package from npm and runs
`tools/build_schema_browser.py` to assemble `static/model/schema-browser/` (gitignored)
with a catalog of Ashlar's own UMF models.

The footer shows the released version. `pages.yml` takes it from the latest `v*` tag and
passes it to Hugo as `HUGO_PARAMS_VERSION`; `release.yml` calls it after each release so the site is restamped.

```sh
npm pack @documentdrivendx/umf-schema-browser@1.1.2
python3 tools/build_schema_browser.py documentdrivendx-umf-schema-browser-1.1.2.tgz
HUGO_PARAMS_VERSION=0.1.0 hugo --source website --destination public --panicOnWarning
python3 website/scripts/check_site.py website/public
hugo server --source website --baseURL http://localhost:1313/ashlar/
```

The runtime ER diagram (`static/model/runtime-er.*`, `layouts/_partials/runtime-er.generated.html`)
is generated by `tools/generate_runtime_diagram.ts`; see
`docs/helix/02-design/models/ashlar-delta-runtime/README.md`.
Expected URL: https://documentdrivendx.github.io/ashlar/.
